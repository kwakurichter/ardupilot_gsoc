FIELD TYPE SET BY MUTATED ON FORWARD? PURPOSE
magic uint8 originator no Frame sync / protocol identifier (0xAB)
version uint8 originator no Header format version; receiver drops unknown versions
origin_id uint8 originator no MAVLink sysid of the vehicle that generated this data. Never changes across hops. Used as peer table key.
prev_hop uint8 each forwarder yes — set to my sysid Immediate sender's sysid. Lets receiver build a next-hop routing table without flooding.
ttl uint8 originator yes — decremented Max remaining hops. Receiver drops if 0. Forwarder decrements before writing.
flags uint8 originator no bit0: ack-requested · bit1: high-priority · bit2–7: reserved
seq uint16 LE originator no (origin_id, seq) pair used for duplicate suppression across all hops.
payload_len uint16 LE originator no Byte length of the MAVLink frame that follows. Lets RX skip unknown payloads cleanly.
Note on CRC: The MAVLink frame already carries its own CRC (computed by mavlink_finalize_message()). The P2P header intentionally has no additional CRC — the header is small and fixed, parse errors are caught by the magic byte check, and a corrupted payload_len will simply fail the MAVLink CRC. If link quality is a concern, a 2-byte CRC-16 over the P2P header can be appended at offset 10, with the MAVLink frame starting at offset 12.
